# Technology for Nature Team Website

Published website: https://tomaugust.github.io/technology-for-nature-website/

This repository contains the source files for the UKCEH Technology for Nature Team website. The site is intended to present the team's people, projects, outputs, and news in a clear, maintainable way, with cross-links between related team members, research activity, publications, datasets, software, hardware, methods, and updates.

The website is built as a static GitHub Pages site using Jekyll. Content is stored as Markdown collection items, with shared metadata and controlled lists in YAML data files.

## Site Structure

- `_people/` contains team member profiles.
- `_projects/` contains current and past project pages.
- `_outputs/` contains publications, reports, datasets, software, hardware, methods, workflows, and other reusable outputs.
- `_news/` contains announcements, events, milestones, media, and new-output updates.
- `_data/` contains navigation items, themes, status lists, output types, and news types.
- `_layouts/` and `_includes/` contain reusable page templates and components.
- `assets/` contains CSS and image assets.

## Aim

The site should help visitors understand who the Technology for Nature Team is, what the team works on, what it produces, and how individual people, projects, outputs, and news items connect to each other.
