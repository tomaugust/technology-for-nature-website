This sample project demonstrates how a project page can combine a short overview, structured metadata, related team members, outputs, news, and images.

The project explores how automated data streams can support biodiversity monitoring, with emphasis on transparent processing, reusable summaries, and decision-ready outputs.

## Objectives

- Connect acoustic, imaging, and environmental data sources.
- Create repeatable workflows for summarising monitoring data.
- Publish reusable outputs that can be linked from project, person, and news pages.
