Phase 2: Architecture & Design
------------------------------
- [x] Finalise the information architecture.
  - Primary navigation: Home, About, Team, Projects, Outputs, News.
  - Secondary discovery routes: Search / Browse and Themes / Tags.
  - Confirm that there is no standalone Tools or Contact page.
  - 2026-05-17: Confirmed in the technical brief under Site Structure and Technical Architecture.
- [x] Define the collection and URL structure.
  - /team/ for people listing and /team/[slug]/ for person pages.
  - /projects/ for project listing and /projects/[slug]/ for project pages.
  - /outputs/ for all outputs and /outputs/[slug]/ for output pages.
  - /news/ for news listing and /news/[slug]/ for news pages.
  - /tags/[tag]/ or equivalent for tag/theme browse pages.
  - 2026-05-17: Confirmed in the technical brief under Technical Architecture.
- [x] Define metadata schemas for each content type.
  - People schema.
  - Projects schema.
  - Outputs schema, including output_type values.
  - News schema, including news_type values.
  - Shared tag/theme schema and controlled lists.
  - 2026-05-17: Detailed schemas and controlled lists added to the technical brief.
- [x] Define relationship rules and display logic.
  - People can link to related projects, outputs, and news.
  - Projects can link to related people, outputs, and news.
  - Outputs can link to related people, projects, and news.
  - News can link to related people, projects, and outputs.
  - Tags/themes should provide cross-category browsing.
  - 2026-05-17: Relationship rules and display logic added to the technical brief.

  - About page.
  - Listing pages for Team, Projects, Outputs, and News.
  - Detail pages for People, Projects, Outputs, and News.
  - Theme / tag browse page.
  - Search / browse page if included in the first build.
  - 2026-05-17: Page template requirements added to the technical brief.

  - Align with UKCEH style where practical.

  - Define how hero images, profile photos, output covers, screenshots, and news images should be used.
  - 2026-05-17: Design principles expanded in the technical brief.
